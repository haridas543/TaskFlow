# TaskFlow – Smart Task Management Website

## About the Project
TaskFlow is a simple and responsive task management website. It helps users manage their work, save time, and improve productivity.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Responsive navigation bar
- Home page with Get Started button
- Three feature sections
- About section
- Free and Premium pricing plans
- Contact form with basic validation
- Success message after form submission

## How to Run the Project
1. Download or clone this project.
2. Open the TaskFlow folder.
3. Double-click index.html.
4. The website will open in your browser.

## Project Files
- index.html – Website structure
- style.css – Website design
- script.js – Website functionality
