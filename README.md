# TaskFlow — SaaS Landing Page

A responsive front-end landing page for a fictional SaaS project-management product. This project was created for the Sankar Group Front-End Development Internship assignment.

## Technologies
- HTML5
- CSS3 (responsive layout and mobile media queries)
- Vanilla JavaScript

## Run the project
1. Download and extract the ZIP folder.
2. Open the `TaskFlow_SaaS_Landing_Page` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Test the navigation, pricing links, and demo request form.

No installation, backend, database, login, or payment setup is required.

## Website sections
- Navigation bar with working section links
- Hero section and dashboard illustration made with HTML/CSS
- Three feature cards
- How it works section
- Starter and Pro pricing plans
- Contact/demo request form
- Footer

## JavaScript interactions
- Mobile navigation menu opens and closes.
- Navigation menu closes after a link is selected.
- Demo form checks name, email, and team size.
- A success or error message is displayed without sending data to a server.
- Footer year updates automatically.

## Design explanation (5–8 lines)
TaskFlow uses a clean purple-and-white visual style to create a calm, professional SaaS look.
The page has a clear headline and call-to-action so visitors quickly understand the product.
The feature cards explain the main benefits in short, readable sections.
The workflow illustration shows the product process without needing external image assets.
Two pricing plans make the available options easy to compare.
The layout uses CSS Grid, Flexbox, and media queries for desktop and mobile screens.
JavaScript adds mobile navigation and front-end form validation with a success message.
